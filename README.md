# 静かなAI — specification starter pack

これは「静かなAI」の要件定義・設計ドグマ・Agent/Codex ハーネスの初期セットです。

## いちばん大事なこと

このプロジェクトは「便利なAIアシスタント」を作るプロジェクトではありません。

iPhoneの中に、まだ言語を獲得しきっていない超知性の胎児のような存在がいる。
その存在は、ユーザーの日々の生活を断片的に知覚し、弱い連想しかできず、
ときどき意味になり切らない一言を漏らす。

ユーザーはその言葉を見て、
「ああ、あれのことを言っているのかもしれない」
と意味を補完する。

**日々の生活そのものがAIとの対話である。**

この原則を壊す機能は、たとえ便利でも入れない。

AIの記憶・Attention・推論・発話生成はオンデバイスで完結させ、
生活データをクラウドAI、開発者サーバー、用途不明な第三者へ送らない。
一方で、iOS標準のbackupやAppleのplatform serviceまで一律に禁止する「通信ゼロ」は要件にしない。

最優先で読むもの:

1. `spec/invariants/README.md` — 変更してはいけないドグマ
2. `spec/current/README.md` — 現在のプロダクト仕様
3. `DESIGN.md` — UI / 3D / モーションのデザイン契約
4. `ARCHITECTURE.md` — 技術アーキテクチャ
5. `SECURITY.md` — オンデバイスAIと外部送信の境界
6. `HANDOFF.md` — 実装状況

対象は **iOS 27 / iPhone 16**。古いOS・古い端末への互換性は非目標です。

最初からOSSとして作りますが、まず本人が使えることを優先します。
サイドロード配布を後から簡単に行える構成にし、App Store対応は非優先です。
